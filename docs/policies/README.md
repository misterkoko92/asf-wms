# Politiques et textes juridiques

Statut global : **brouillons a valider juridiquement / RGPD avant publication**.

Ce dossier regroupe les documents de travail crees pour traiter P1-02 de l'audit
du 2026-04-22. Ils fournissent une base operationnelle, mais ne ferment pas le
risque tant qu'un validateur humain n'a pas confirme les hypotheses juridiques.

## Documents

- `rgpd.md` : registre de travail RGPD, traitements, sous-traitants, transferts,
  retention et checklist de validation.
- `confidentialite.md` : politique de confidentialite publique / portail.
- `cgu-portail.md` : conditions generales d'utilisation du portail.
- `mentions-legales.md` : base de mentions legales avec placeholders ASF.
- `mentions-information-formulaires.md` : mentions courtes reutilisables sous les
  formulaires publics et portail.
- `droits-des-personnes.md` : procedure interne d'exercice des droits RGPD.
- `translation-paused.md` et `next-migration-paused.md` : politiques de scope repo
  independantes du chantier RGPD.

## Validation requise

Avant publication ou integration dans l'interface, confirmer :

- responsable de traitement ;
- referent RGPD ou DPO ;
- statut juridique et adresse officielle d'ASF / Messagerie Medicale ;
- contacts officiels ;
- bases legales par traitement ;
- durees de conservation ;
- garanties des sous-traitants et transferts hors UE ;
- processus d'acceptation CGU ;
- procedure de traitement des demandes de droits.
